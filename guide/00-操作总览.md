这一份是**索引**，不是新内容：告诉你现在该做什么、东西都在哪、每步怎么算成功。
每一步后面都标着「细节看哪一份」，照着点过去就行。

## 一、你要改的就两个文件

整个项目你只需要碰这两个文件，其余全是代码或自动生成物：

| 文件 | 管什么 |
|---|---|
| `dashboard/config.yaml` | 城市、自选股、天气源 Key、**出图时刻表**、时钟样式 |
| `kindle/extensions/aistatus/config.sh` | 图片地址（云端 + 局域网备用）、刷新节奏、时钟开关、省电 |

> **改完 `dashboard/` 里任何东西，必须重新发布一次云端**，线上才会变（链接不变）。
> Kindle 那边不用动 —— 它每次下载拿到的自然就是新图。

## 三、操作顺序（就按这个顺序做）

| # | 做什么 | 在哪做 | 怎么算成功 | 细节 |
|---|---|---|---|---|
| 1 | 装 **hotfix（版本 ≤ 2.3.7）并运行它** → 拷 **KUAL / MRPI** → 装 **renameotabin** 挡住 OTA | Kindle | 书库里的 KUAL 能**正常打开**（不报 `Application Error`） | [01 §2.4–4](01-越狱与基础环境.md) |
| 2 | 把 `kindle/extensions/aistatus/` **整个文件夹**（含 `clock/`）拷到 Kindle 的 `/mnt/us/extensions/` | USB 连电脑 | Kindle 里能看到 `aistatus` | [02 §1](02-Kindle端部署.md) |
| 3 | 打开 `config.sh`，确认两个图片地址 | 电脑 | — | [02 §2](02-Kindle端部署.md) |
| 4 | KUAL → **🕐 时钟贴图自检（真机必做）** | Kindle | 时钟出现在**右上角** | [02 §3.1](02-Kindle端部署.md) |
| 5 | KUAL → **⟳ 测试下载并刷新一次（排障用）** | Kindle | 屏幕换成信息屏 | [02 §3.2](02-Kindle端部署.md) |
| 6 | KUAL → **▶ 启动信息屏** | Kindle | 画面稳定，之后自己转 | [02 §4](02-Kindle端部署.md) |

> **第 1 步里埋着一个坑，先说在前面**：hotfix **别用最新的 2.5.x**。它换了 KUAL 的
> 签名证书，结果是 KUAL 图标会正常出现在书库里、但一点就报
> `Application Error / The selected application could not be started`，
> 而且**降级回去也修不好，只能重新越狱**。用 **2.3.7**。
> 详见 [01 §2.4](01-越狱与基础环境.md)。

**别跳第 4 步。** 它是全项目唯一一个只能在真机上验证的环节：

- 时钟在**右上角** → 一切正常，继续第 5 步
- 时钟跑到**左上角** → 这台固件忽略 `eips -x/-y`。把 Kindle 上 `CLOCK_MODE` 改成 `off`，
  同时把电脑上 `dashboard/config.yaml` 的 `clock.mode` 改回 `image`（时钟重新画进图里），
  然后重新发布云端。其余一切照常，只是时间精度回到"跟着整图更新"
- **什么都没有** → 精灵图没拷全，回第 2 步确认 `clock/` 里是 1440 张 png + 1 个 `clock.conf`

改字号、字体、时钟样式、版面之后，**按顺序**跑这三条。它们不是摆设 ——
每一条都对应一个真踩过的坑（换字体会让时钟贴偏、改字号会让坐标过期）。

```powershell
cd "C:\Users\peqw0\WorkBuddy\Kindle Plan"
```

## 五、日常怎么用

**装好之后什么都不用做。** 电脑可以关机，Kindle 自己会：

- 每分钟醒来一次，用自己的系统时间在右上角贴一次钟
- 每天 4 个时刻（00:05 / 05:10 / 12:00 / 15:05，北京时间）来拉一张新图
- 其余时间真休眠，墨水屏保持画面是零功耗

### 想让它停下来

| 情况 | 怎么做 |
|---|---|
| 正常运行中想停下来（`STOP_FRAMEWORK=1` 时） | USB 连电脑，在 `extensions/aistatus/` 里新建一个**空文件**，名叫 `.stop`；最多一分钟后它自己退出并恢复书架界面 |
| 万能保底，任何情况下都管用 | 长按电源键 **40 秒** 强制重启，系统完全恢复原样 |
| `STOP_FRAMEWORK=0`（保留了原生界面） | KUAL → **■ 停止信息屏** |

### 想让它更省电

时钟每分钟醒一次是这个项目唯一"费电"的地方（唤醒次数从每天几十次涨到 1440 次）。
嫌续航短就把 Kindle 上 `CLOCK_INTERVAL` 调大，比如 `300`（每 5 分钟贴一次）——
代价是屏幕上的分钟数会以 5 分钟为单位跳。**改这个不用重新生成任何东西。**

## 六、一条命令速查

```powershell
# 出图（跑一次 = 出一张到 docs/）
python dashboard\generate.py -c dashboard\config.yaml

# 局域网服务（备用方案，这个窗口要一直开着）
python dashboard\serve.py

# 注册每天 4 个时刻自动出图（Windows 计划任务）
python dashboard\tools\install_task.py
python dashboard\tools\install_task.py --at 07:30,12:00,18:30   # 临时换时刻
python dashboard\tools\install_task.py --status                 # 看上次结果
python dashboard\tools\install_task.py --remove                 # 注销
```

> 走云端为主时，计划任务只服务备用方案，不装也行。

## 出问题了

先做这一件事：**用浏览器打开图片地址**（`config.sh` 里那个）。
打得开且内容是新的 → 问题在 Kindle 那边；打不开或内容是旧的 → 问题在出图那边。

这一步能立刻把范围砍掉一半。然后对号入座翻
[04 排障手册](04-排障手册.md) —— 它按"A 脚本 / B 屏幕 / C 下载 / D WiFi / E 电脑端"分了区。
